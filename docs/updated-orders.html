Two runs are included. File A is the real run against the live OpenWeatherMap API and is the actual deliverable. On the day it was generated all three valid cities were clear or cloudy, so no order met the Rain / Snow / Extreme condition and nothing was marked Delayed — real weather does not take direction. File B is the identical pipeline over deterministic offline fixtures, included so the Delayed path and the generated customer messages are visible. Only fetch differs between them; classification, retry and error handling are the same code.
